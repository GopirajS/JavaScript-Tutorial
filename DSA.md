# **How to practise each question**

For every problem, follow this format:

1. Understand the input.
2. Understand the expected output.
3. Write the logic in plain English.
4. Solve using JavaScript without built-in shortcuts initially.
5. Test with additional inputs and edge cases.
6. Understand the time and space complexity.

Example:

**Practice Question #1 – Find the largest number**

**Input**

```
let numbers = [10, 25, 5, 40, 15];
```

**Expected Output**

```
40
```

**Your task:** Write a JavaScript function to find the largest number without using `Math.max()`.

Show reference solution
